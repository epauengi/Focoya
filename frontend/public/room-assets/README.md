# Room assets

| Focus Room | Artwork | Fallback API theme | Ambience |
| --- | --- | --- | --- |
| Rainy Café | `rainy.jpg` | `Café`, `Study` | Rain |
| Midnight Library | `midnight.png` | `Gaming` | Quiet library texture |
| Autumn Forest | `autumn.png` | `Nature` | Forest wind |
| Sunset Beach | `sunset.jpg` | `Chill` | Ocean waves |

Wallpaper overrides room artwork and selects matching effects and automatic sound. Unknown or unavailable artwork falls back through the matching room theme to `bg.png` (static), then the solid room background. Effects are decorative and hidden when reduced motion is active.

Audio is original procedural filtered noise generated by `ambientAudio.ts` using Web Audio. No recordings, third-party media, or additional audio license/attribution requirements.

- `autumn.png`, `bg.png`, `midnight.png`, `rainy.jpg`, `sunset.jpg`: copied from `FE TEST/assets/`; artwork unchanged. Origin embedded as image metadata. Some prototype `.png` files contain JPEG data; filenames retained for compatibility.
- `cloud.svg`, `home.svg`, `settings.svg`, `fullscreen.svg`: copied from `FE TEST/assets/`.
- `bulb.svg`: replacement SVG authored during the React integration; original prototype export rendered incorrectly.

Original artwork author/license not supplied in the prototype. Confirm redistribution rights before public release. No new stock downloads or generated raster artwork.
